import random

angka_rahasia = random.randint(1, 10)
print("Gue udah mikir angka 1 sampai 10!")

4. MATERI 4: Variabel Penghitung - BOSS FINAL 1-100

Fungsinya: Buat ngitung, skor, dan level yang lebih susah.

import random

angka_rahasia = random.randint(1, 100)
percobaan = 0
print("BOSS FINAL! Angka 1 sampai 100!")

while True:
    tebakan = int(input("Tebakan lu: "))
    percobaan = percobaan + 1

    if tebakan == angka_rahasia:
        print("BOSS FINAL KALAH!")
        break
    elif tebakan < angka_rahasia:
        print("KECILAN!")
    else:
        print("KEGEDEAN!")

print("Angka rahasianya:", angka_rahasia)
print("Lu menang dalam", percobaan, "kali tebakan!")

- percobaan = 0 = Tempat nyimpen skor
- percobaan = percobaan + 1 = Tiap nebak, tambah 1
- Lu menang pake strategi Binary Search: tebak tengah, persempit terus.
